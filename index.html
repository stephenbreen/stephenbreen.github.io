Stephen Breen

I write software in Cork, Ireland: Azure platforms and telematics pipelines by day, tools for D&D tables and terminals the rest of the time. This page is mostly the latter, because that's the stuff you can click.

Most of it started at a real game night, or because something in my terminal annoyed me. Usually both.

~/made

at the table

  • turnkeeper TypeScript · try it ↗

    Initiative tracker for dungeon masters. Two windows, one fight: you drive, the players watch a second screen. Turn timers, lair and legendary actions, injury triggers and a campaign library. No backend, no accounts.

  • bastion-builder TypeScript

    Stronghold tracker for D&D 5e (2024): bastion facilities and downtime between adventures, blending the DMG 2024 rules with MCDM's Strongholds & Followers.

  • corkdnd the club itself

    Cork D&D Club, where everything above gets stress-tested across a real table. Come play if you're local.

in the terminal

  • git-tagger Rust

    A terminal UI for browsing git tags and seeing exactly which commits shipped between them. Built with ratatui and git2.

  • memo Python

    Flashcards for your own shell commands and aliases — for the day you finally learn that shortcut you keep re-googling.

  • ogham-note Swift

    A native macOS Markdown editor with a real Vim engine: modal editing, zero Electron, near-zero latency.
